Scorecard de risco de crédito

Probabilidade de inadimplência convertida em score, com validação, política de corte e monitoramento.

Código no GitHub
Dados
Give Me Some Credit (Kaggle), cerca de 150 mil tomadores.
Método
Faixas monotônicas com WoE e IV, regressão logística com checagem de sinais, modelo XGBoost como comparação e monitoramento por PSI.
Resultado
No teste, Gini de 0,706 e KS de 0,551 (XGBoost: 0,734 e 0,580). A taxa de inadimplência cai de 36,4% na pior faixa para 0,5% na melhor. PSI treino vs. teste de 0,0003.
Decisão
Um corte de 545 pontos aprova 88,7% dos proponentes com 3,2% de inadimplência entre os aprovados, sob premissas de custo ilustrativas.
Ferramentas
Python, scikit-learn, XGBoost, pytest, GitHub Actions.

API de detecção de fraude em cartões

Do modelo ao serviço: features sem vazamento, validação fora do tempo, decisão por custo e API em container.

Código no GitHub
Dados
Fraud Detection Handbook, 1,75 milhão de transações simuladas.
Método
Histórico de cliente e terminal com defasagem de 7 dias nos rótulos, XGBoost, limiares de revisão e bloqueio definidos por custo, e os principais motivos de cada decisão.
Resultado
No teste fora do tempo, PR-AUC de 0,748 (regressão logística: 0,680; só o valor da transação: 0,241) e precisão de 62,6% nos 100 maiores scores de cada dia.
Decisão
Redução de custo de 87,7% contra não ter modelo, sob premissas ilustrativas.
Serviço
API FastAPI com latência mediana de 3 ms (localhost, 1 CPU) e testes contra vazamento de dados e contra divergência entre treino e produção.
Ferramentas
Python, XGBoost, FastAPI, Docker, Streamlit, pytest.

Como os dados são simulados, esses números não representam o desempenho em fraude real.

Monitor de crédito e inadimplência no Brasil

Pipeline de dados em camadas com dados abertos do Banco Central e um painel de acompanhamento.

Código no GitHub
Dados
Oito séries mensais do SGS, do Banco Central: inadimplência (total, pessoas físicas, pessoas jurídicas, cheque especial e consignado), juros médios do crédito e Selic.
Método
Ingestão da API com repetição e validação, camadas bronze, silver e gold em SQL (DuckDB), tratamento das revisões do Banco Central e alertas por z-score sobre a variação mensal.
Qualidade
9 checagens de qualidade de dados que interrompem o pipeline antes de gerar o painel, incluindo a consistência entre a inadimplência total e a de pessoas físicas e jurídicas.
Engenharia
31 testes com defeitos injetados nos dados, integração contínua e fluxo de execução mensal.
Ferramentas
Python, SQL, DuckDB, pandas, matplotlib, GitHub Actions.
